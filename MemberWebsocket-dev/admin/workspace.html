我的商家管理頁面

何時可以開始使用？

審核通過後即可使用已核准的管理功能及專屬用戶端。請在管理功能內儲存業務內容；自有 LINE 入口與通知設定可另外完成。

設定清單

依已儲存資料檢查完整度；格式正確不代表 LINE 已連線成功。

不知道 LINE 資料去哪裡找？查看完整教學
  1. 開啟 LINE Developers Console，選擇商家擁有的 Provider。LINE Login 與 Messaging API Channel 必須在同一 Provider，才能對應同一用戶。
  2. 建立 LINE Login Channel，App types 選 Web app。在 Basic settings → Channel ID 複製登入 Channel ID。管理端、會員端可用同一 Login Channel；若使用不同 Channel，請分別填寫對應 ID。
  3. 在 LINE Official Account Manager 的設定啟用 Messaging API，選擇同一 Provider。回 LINE Developers 開啟該 Messaging API Channel，從 Basic settings 複製 Channel ID、Channel secret；從 Messaging API → Channel access token (long-lived) → Issue 取得 token。已有 token 請沿用；重新發行會讓原 token 失效，請先確認其他服務的使用情況。Secret 與 token 只填在下方密碼欄位，不要傳送給其他人。
  4. 開啟對應 LINE Login Channel 的 LIFF → Add，Size 選 Full，Scopes 勾選 openid、profile。每個已核准的用戶功能建立自己的 LIFF，將 LIFF ID 貼回該功能頁。LIFF ID 的數字前綴應等於該 Login Channel ID。
  5. Endpoint URL 需使用平台提供的商家專屬 HTTPS 網址。審核通過後，本頁會顯示各功能完整網址（包含 business 商家代碼）；請完整複製，保留商家參數。
  6. 先儲存共用設定，再逐頁儲存已核准功能。完成 LINE 設定後，需確認 Channel 已 Published、LIFF Endpoint 與功能相符，並以管理員及另一個測試用戶實際登入。管理業務不需等待 LINE 設定；自有 LINE 入口實測完成後即可放入官方帳號選單。

申請與設定仍使用本平台的管理員登入；你填入的商家管理端 LIFF 不會立即更換目前的登入入口。平台會在專屬服務開通時處理商家管理員身分綁定。
