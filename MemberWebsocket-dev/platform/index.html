獨立商家

各商家使用獨立會員與業務資料，功能由總管理員逐項設定。

新商家儲存後為「待佈建」。完成獨立資料環境與登入驗證後，才能啟用會員、票券與預約等功能。

核准功能

核准只開放 LINE 設定權；商家業務功能需完成獨立資料環境驗證後才能啟用。

申請商家管理員

使用 LINE 身分送出申請，由總管理員審核可使用的功能。

我的商家管理頁面

總管理員只核准可使用的功能。每項 LINE 設定由本商家管理員自行管理；商家資料隔離完成前，所有業務操作仍維持停用。

共用 LINE Channel 與管理端登入

先設定共用 Channel，再到已核准的各功能頁面設定自己的 LIFF ID。憑證只儲存在後端，從不回填。

會員卡 — LINE 設定

設定會員卡專用 LIFF 入口，使用共用會員端 Login Channel。

集點卡 — LINE 設定

設定集點卡專用 LIFF 入口。

活動票券 — LINE 設定

設定活動票券專用 LIFF 入口。

營運日曆 — LINE 設定

設定營運日曆專用 LIFF 入口。

預約 — LINE 設定

設定預約服務專用 LIFF 入口。

整合中心 — LINE 設定

整合中心使用共用 Messaging API Channel 與伺服器憑證；不需建立額外 LIFF ID。

測試 — LINE 設定

測試功能沿用已設定的 LINE 測試入口與共用 Channel。測試工具的業務權限仍受商家隔離狀態限制。

使用紀錄 — LINE 設定

使用紀錄由已核准功能產生，不需額外的 LIFF ID；存取紀錄仍由伺服器驗證權限。
